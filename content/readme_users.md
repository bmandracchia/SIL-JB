# Sistemas Lineales — Jupyter Book

Este repositorio contiene un Jupyter Book para la docencia de Sistemas Lineales. Incluye contenido teórico, ejemplos y visualizaciones interactivas.

---

## Estructura del repositorio

```

├─ Tema 1. Introducción a los sistemas lineales/               
├─ Tema 3. Análisis de Fourier para señales en tiempo continuo/             
├─ Tema 7. La Transformada Z/
```

---

En cada tema se pueden encontrar sub-apartados que contienen Definiciones, Figuras, Ejercicios y Soluciones, Notas.
Al final de cada tema hay una sección de ejercicios resueltos y de ejercicios de autoevaluación.

---

### Notación matemática
La notación matemética que se mantiene a lo largo de todo el repositorio es:
  * entrada: `$x(t)$`
  * salida: `$y(t)$`
  * respuesta impulsional: `$h(t)$`
  * tiempo continuo: `$t$`
  * tiempo discreto: `$n$`

### Texto docente

* Cada ecuación importante está detalladamente explicada.
* Los ejercicios presentan un enunciado mientras que las soluciones se presentan a continuación como bloques desplegables.


### Figuras
* Todas cuentan con un pie de figura.
* Algunas de las figuras son interactivas permitiendo al alumno explorar la influencia de ciertos parámetros en los resultados.
